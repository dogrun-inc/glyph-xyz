# glyph-xyz
ブラウザ上で動作する3Dアンビグラム自動生成Web CADアプリ

## 現在の仕様（Phase 2）

Web Worker 上で Pyodide と build123d を起動し、基準サイズに応じたテスト立体を生成します。テスト立体は、Z 軸方向に一辺の半分の直径の貫通穴があるブロックです。

画面は高さ `100vh` の2ペイン構成です。左に幅320 pxの操作パネル、右に残りの幅を使う3Dビューアを配置しています。

### 操作パネル

| 項目 | 仕様 |
| --- | --- |
| 軸の文字 | X・Y・Zの入力欄を横並びに表示し、各欄は1文字まで入力できます。初期値は順に `G`、`E`、`B` です。 |
| 基準サイズ | ブロックの一辺を指定します。初期値は30 mmで、5〜200 mmの範囲で小数も入力できます。 |
| フォント | `.ttf` と `.otf` を選択できます。フォントの読み込みは今後の実装です。 |
| 立体を生成 | 準備完了後に有効になります。クリックすると現在の基準サイズでテスト立体を生成し、描画が終わるまでボタンが無効になります。 |
| ステータスと警告 | Pyodide の読み込み、build123d と Plotly のインストール、準備完了、CAD 計算中、描画結果やエラーを表示します。パーツ分断警告欄は非表示です。 |
| エクスポート | STL・STEPのダウンロードボタンは無効です。 |

### 3Dビューア

- 初期表示は一辺30 mmの立方体（Plotly `mesh3d`）を、平行投影の斜め視点から描画します。
- ビューア上部のツールバーで平行投影と透視投影を切り替えられます。+X、-Y、+Zの正面視点と、初期の斜め視点を選べます。
- テスト立体を生成・再生成しても、選択した投影モードとカメラの視点を引き継ぎます。
- XYZ軸の表示比率はデータに従い、ビューアのサイズはウィンドウのリサイズに追従します。

軸の文字を使ったアンビグラム生成、フォント読み込み、パーツ分断の検出、STL・STEP出力は今後の実装です。

## ローカルでの起動

リポジトリ直下で次を実行します。

```sh
python -m http.server 8000
```

WebGLが有効なブラウザで `http://localhost:8000/` を開きます。Plotly.js 2.35.2 と Pyodide 0.29.5 を CDN から、Python パッケージを OCP.wasm と PyPI から取得するため、インターネット接続が必要です。Pyodide 0.29.5 は、OCP.wasm が配布する Python 3.13 用の CAD wheel に合わせて固定しています。

1. 初回ロードでは立方体のプレビューを見ながら、「Pyodide を読み込み中...」→「build123d をインストール中...」→「plotly をインストール中...」→「準備完了」と進むことを確認します。初回のパッケージ取得には時間がかかる場合があります。
2. 「立体を生成」を押し、「CAD ジオメトリを計算中...」の間はボタンが無効になることを確認します。「+Z 視点」を選ぶと、生成したブロックの中央に円形の穴が見えます。
3. 透視投影に切り替えて基準サイズを変更し、再生成します。ブロックの寸法が変わり、透視投影と視点が維持されることを確認します。

## ファイル構成

素のHTML・CSS・JavaScriptで構成しており、Node.jsやビルド工程は不要です。

- `index.html` は操作パネルとビューアの要素を定義し、Plotly.jsを読み込みます。
- `style.css` は2ペインのレイアウトと操作要素の表示を定義します。
- `main.js` はプレビューとカメラ操作を実装し、Worker に基準サイズを渡します。受け取った Figure JSON を解析し、現在の投影モードとカメラを引き継いで `Plotly.react` で描画します。
- `worker.js` は Pyodide で build123d 0.11.0 と Plotly 5.24.1 を初期化します。ブロックから円柱を差し引き、形状を三角形メッシュに変換して Plotly `Mesh3d` の Figure JSON を返します。
