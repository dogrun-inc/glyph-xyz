# glyph-xyz
ブラウザ上で動作する3Dアンビグラム自動生成Web CADアプリ

## 現在の仕様（Phase 1）

画面は高さ `100vh` の2ペイン構成です。左に幅320 pxの操作パネル、右に残りの幅を使う3Dビューアを配置しています。

### 操作パネル

| 項目 | 仕様 |
| --- | --- |
| 軸の文字 | X・Y・Zの入力欄を横並びに表示し、各欄は1文字まで入力できます。初期値は順に `G`、`E`、`B` です。 |
| 基準サイズ | 初期値は30 mmで、入力欄の範囲は5〜200 mmです。 |
| フォント | `.ttf` と `.otf` を選択できます。未選択時はデフォルトフォントを使用する旨を表示します。 |
| 立体を生成 | クリックすると、立方体のプレビューを表示中であることをステータス欄に案内します。 |
| ステータスと警告 | 初期表示は「準備完了（プレビュー表示中）」です。パーツ分断警告欄は非表示です。 |
| エクスポート | STL・STEPのダウンロードボタンは無効です。 |

### 3Dビューア

- 初期表示は一辺30 mmの立方体（Plotly `mesh3d`）を、平行投影の斜め視点から描画します。
- ビューア上部のツールバーで平行投影と透視投影を切り替えられます。+X、-Y、+Zの正面視点と、初期の斜め視点を選べます。
- XYZ軸の表示比率はデータに従い、ビューアのサイズはウィンドウのリサイズに追従します。

Phase 1の描画対象は固定の立方体です。入力値やフォントに基づく立体生成、パーツ分断の検出、STL・STEP出力、Pyodide・Web Worker連携は未実装です。

## ローカルでの起動

リポジトリ直下で次を実行します。

```sh
python -m http.server 8000
```

WebGLが有効なブラウザで `http://localhost:8000/` を開きます。Plotly.js 2.35.2をCDNから読み込むため、インターネット接続が必要です。

## ファイル構成

素のHTML・CSS・JavaScriptで構成しており、Node.jsやビルド工程は不要です。

- `index.html` は操作パネルとビューアの要素を定義し、Plotly.jsを読み込みます。
- `style.css` は2ペインのレイアウトと操作要素の表示を定義します。
- `main.js` はプレビューとカメラ操作を実装します。`renderFigure(figureJson)` はFigureオブジェクトの `data` と `layout` を `Plotly.react` に渡し、投影と視点の変更には `Plotly.relayout` を使います。
