# glyph-xyz
ブラウザ上で動作する3Dアンビグラム自動生成Web CADアプリ

## 現在の仕様（Phase 3）

X・Y・Z の各方向から指定した文字に見える立体を生成します。Web Worker 上の build123d が各文字の輪郭を同じ正方形に正規化し、三方向に両側押し出しした形状の共通部分を作ります。文字とフォントの組み合わせによって、投影で字画の一部が欠けたり、立体が複数のパーツに分かれたりすることがあります。

画面は高さ `100vh` の2ペイン構成です。左に幅320 pxの操作パネル、右に残りの幅を使う3Dビューアを配置しています。

### 操作パネル

| 項目 | 仕様 |
| --- | --- |
| 軸の文字 | 各欄の先頭の空白を除いた最初の1文字を使います。初期値は X が `G`、Y が `E`、Z が `B` です。空欄や、選択したフォントに収録されていない文字はエラーになります。 |
| 基準サイズ | 文字輪郭を正規化する正方形の一辺です。初期値は 30 mm で、5〜200 mm の範囲で小数も入力できます。 |
| フォント | `.ttf` または `.otf` を選べます。未選択の場合は `fonts/default.ttf` を使います。 |
| 立体を生成 | 初期化中と生成中は、生成ボタンとフォント入力がグレー表示になり、操作できません。生成後はエラー時も含めて操作できる状態に戻ります。 |
| ステータスと警告 | 初期化、フォント読み込み、CAD 計算、描画の進行状況を表示します。共通部分が空ならエラーを表示し、複数のパーツに分かれた立体は描画したうえでパーツ数を警告します。 |
| エクスポート | STL・STEPのダウンロードボタンは無効です。 |

### 3Dビューア

- 初期表示は一辺30 mmの立方体（Plotly `mesh3d`）を、平行投影の斜め視点から描画します。
- ビューア上部のツールバーで平行投影と透視投影を切り替えられます。+X、-Y、+Zの正面視点と、初期の斜め視点を選べます。
- 立体を生成・再生成しても、選択した投影モードとカメラの視点を引き継ぎます。
- XYZ軸の表示比率はデータに従い、ビューアのサイズはウィンドウのリサイズに追従します。

## ローカルでの起動

リポジトリ直下で次を実行します。

```sh
python -m http.server 8000
```

WebGL が有効なブラウザで `http://localhost:8000/` を開きます。Plotly.js 2.35.2 と Pyodide 0.29.5 は CDN から、Python パッケージは OCP.wasm と PyPI などから取得します。文字輪郭の修復が必要な場合は Skia PathKit も CDN から取得するため、インターネット接続が必要です。Pyodide 0.29.5 は、OCP.wasm が配布する Python 3.13 用の CAD wheel に合わせて固定しています。

1. 初回ロードでは立方体のプレビューを見ながら、「Pyodide を読み込み中...」→「build123d をインストール中...」→「plotly をインストール中...」→「準備完了」と進むことを確認します。初回のパッケージ取得には時間がかかる場合があります。
2. 「立体を生成」を押します。初期値で生成したら、平行投影で `+X`、`-Y`、`+Z` の各視点に切り替え、順に `G`、`E`、`B` の見え方を確認します。
3. 別の TTF または OTF を選び、文字や基準サイズを変えて再生成できます。日本語の文字を使う場合は、その文字を収録したフォントを選択してください。

## ファイル構成

素のHTML・CSS・JavaScriptで構成しており、Node.jsやビルド工程は不要です。

- `index.html` は操作パネルとビューアの要素を定義し、Plotly.jsを読み込みます。
- `style.css` は2ペインのレイアウトと操作要素の表示を定義します。
- `main.js` は操作の無効化、フォントの読み込み、カメラ操作を担当します。文字、基準サイズ、フォントを Worker に渡し、結果を `Plotly.react` で描画します。
- `worker.js` は Pyodide で build123d 0.11.0 と Plotly 5.24.1 を初期化します。フォントを仮想ファイルシステムに保存し、`cmap` で文字の収録を確認します。文字から作った CAD 面が無効な場合は、FontTools と Skia PathKit で重複輪郭を除去して再検証します。立体を三角形メッシュに変換し、Plotly `Mesh3d` の Figure JSON とソリッド数を返します。
